# Oceanic Dark

A sleek, modern Visual Studio Code theme and icon pack inspired by Sublime Text, featuring a clean dark background with vibrant, oceanic colors. Perfect for developers who want a visually appealing and distraction-free coding experience.

---

## Features

- **Oceanic Dark Color Theme:**  
  Carefully crafted color palette for syntax highlighting, UI elements, and editor backgrounds, providing excellent readability and reduced eye strain.
- **Oceanic Dark Icon Theme:**  
  Custom file and folder icons designed to complement the color theme, supporting a wide range of languages and file types.
- **Consistent Look:**  
  Both theme and icons are designed to work together for a seamless, unified appearance.

---

## Installation

1. **From VS Code Marketplace:**
   - Search for `Oceanic Dark` in the Extensions view (`Ctrl+Shift+X`).
   - Click **Install**.

2. **Manual Installation:**
   - Download or clone this repository.
   - In VS Code, go to the Extensions view, click the `...` menu, and choose **Install from VSIX...** if you have packaged the extension.

---

## Usage

1. **Activate the Color Theme:**
   - Open the Command Palette (`Ctrl+K Ctrl+T` or `Cmd+K Cmd+T` on macOS).
   - Select **Oceanic Dark** from the list.

2. **Activate the Icon Theme:**
   - Open the Command Palette (`Ctrl+Shift+P` or `Cmd+Shift+P` on macOS).
   - Type `icon theme` and select **File Icon Theme: Oceanic Dark Icons**.
